An operating system written in V

Modern, fast,
and useful.

Vinix is an effort to build a practical operating system in the V programming language—with simple code, modern hardware in mind, and enough Linux compatibility to bring useful software along.

Project roadmap

Already running.
Still moving.

The foundation reaches from a native toolchain and familiar userland to desktops on both major architectures.

Available today

  • mlibc, bash, GCC/G++, V, and nano
  • Storage drivers and ext2
  • X.org and an X window manager
  • Wayland with Hyprland on aarch64
  • Intel VT-x hypervisor

On the horizon

  • Networking
  • V-UI
  • Intel HD graphics driver

M1 MacBook Air snapshot

Vinix and the latest macOS.

A practical look at the current Vinix nightly beside macOS Tahoe 26.5.1 on the 2020 M1 MacBook Air. This is a development-status comparison, not a performance claim.

Vinix nightly and macOS Tahoe 26.5.1 on a 2020 M1 MacBook Air
Measure Vinix nightly macOS Tahoe 26.5.1
Memory to start 8 GiB recommended The desktop root filesystem is currently loaded into RAM. 8 or 16 GB installed The M1 MacBook Air shipped with 8 GB, configurable to 16 GB.
RAM used at idle Measurement pending The built-in Activity Monitor now reports real used and free memory. No fixed Apple figure Usage varies with configuration, login items, and background services.
Cold boot to desktop Measurement pending A same-device cold-boot result has not been recorded yet. No fixed Apple figure Apple does not publish a standard M1 cold-boot time.
Native architecture AArch64Kernel and native desktop written in V. Apple siliconDarwin/XNU with the Aqua desktop.
Apps and compatibility Growing Linux compatibility V, GCC, Firefox ESR, bash, and selected Linux software. Production macOS ecosystem Native Mac applications and mature developer tooling.
M1 hardware support Experimental Display, input, battery, Wi-Fi, and storage work is in active development. Fully supportedThe M1 Air is on Apple's Tahoe compatibility list.
Release status Pre-alpha nightlyFor development and testing. Supported releaseFor everyday and production use.

Numeric RAM-at-idle and boot-time results will be added after both systems are measured from a cold start on the same M1 MacBook Air. Sources: latest macOS version, Tahoe compatibility, and M1 MacBook Air specifications.
